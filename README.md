## What it is

Grand Theft Auto VI released 19 Nov 2026. This is a free, open-source, offline trophy guide and tracker anyone can host or fork:

- **Tracker** — all 55 official trophies (1 platinum, 2 gold, 6 silver, 46 bronze) with name, description and grade from the official list, a checklist saved in your browser (localStorage) with export and import, filters by kind and grade, search, and a spoiler setting that hides story trophies until you earn them.
- **Roadmap to the platinum** — the story first, then stranger strands, activities, collectibles, heists and clean-up, in order.
- **Missables** — six trophies flagged from the official descriptions alone, with the reason each one may not come back.
- **Guides in our own words** — every trophy has a guide that cites its sources (the official Exophase list for name, description and grade; PSNProfiles where a trophy carries a PSN count). Where a place or a trigger is not pinned down, the guide says so instead of inventing one. No other guide's text is copied here.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no build step, no network requests, plain static files.
